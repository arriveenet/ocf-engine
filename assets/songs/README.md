## Song License

This directory contains songs for the tracker (`tools/tracker`), in the format described in `docs/tracker-format.md`.

"Canon in D" (canon_in_d.json)
Composed by Johann Pachelbel (1653-1706). The composition is in the public domain.
This arrangement for the NES APU was made for this repository and is licensed under the MIT License, like the rest of the repository.

"Air on the G String" (air_on_the_g_string.json)
The Air from Orchestral Suite No. 3 in D major, BWV 1068, composed by Johann Sebastian Bach (1685-1750). The composition is in the public domain.
This arrangement for the NES APU was made for this repository and is licensed under the MIT License, like the rest of the repository.
