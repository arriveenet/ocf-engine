# OCF Tracker

NES APU（ファミコンの音源）で鳴らす曲を作る、FamiTracker風のトラッカーです。
作った曲はJSONファイルに保存し、OCF Engine のゲームからそのまま再生できます。

- チャンネル: Pulse 1 / Pulse 2 / Triangle / Noise / DPCM
- インストゥルメント: 音量・デューティのシーケンス
- エフェクト: `Fxx`（スピード・テンポ）、`Bxx`（フレームへジャンプ）、`Dxx`（次のフレームへ）、`Cxx`（停止）

## ビルドと起動

```
cmake -S . -B build
cmake --build build --config Debug --target tracker
build/tools/tracker/Debug/ocf_tracker.exe
```

- リポジトリ内のどこから起動してもかまいません（`assets` フォルダを上にたどって探します）。
- Dear ImGui を使うので、`OCF_ENABLE_IMGUI=OFF` のときはビルドされません。
- 起動するとデモ曲が開いた状態になります。`F5` で再生、`F8` で停止します。

## 画面

```
+---------------------------------------------------------------------------+
| File  Edit  Playback  Help                        song.json*    Stopped   |
+--------------------+------------------------------------------------------+
| Song               | Pattern                                              |
|  タイトル・テンポ  |  [Play] [Play Frame] [Stop]  Octave  Step  Edit Mode |
+--------------------+  Pulse 1    Pulse 2    Triangle   Noise     DPCM     |
| Frames             |  00 C-5 00 . ...  ...      C-3 02 . ...  ...        |
|  再生順            |  01 ...                                             |
+--------------------+  02 ...                                             |
| Instruments        |                                                      |
|  音色              |                                                      |
+--------------------+------------------------------------------------------+
```

| ウィンドウ | 内容 |
| --- | --- |
| `Song` | タイトル、作者、`Speed`、`Tempo`、1パターンの行数（`Rows`） |
| `Frames` | 再生順。1行が1フレームで、各チャンネルが再生するパターン番号を並べます |
| `Instruments` | インストゥルメントの一覧と、音量・デューティのシーケンス |
| `Pattern` | カーソルのあるフレームのパターン。ここにノートを打ち込みます |
| `DPCM Samples` | DPCMのサンプルの読み込み・書き出し。`View` → `DPCM Samples` で開きます |

メニューバーの右端には、ファイル名（未保存なら `(untitled)`、変更があれば `*`）と再生状態が出ます。

トラッカーでは、曲を次のように組み立てます。

- **パターン**: チャンネルごとの、決まった行数の譜面です。チャンネルごとに番号（`00`〜`FF`）があります。
- **フレーム**: 「各チャンネルがどのパターンを鳴らすか」の組です。曲はフレームを上から順に再生し、最後まで来ると先頭に戻ります。
- 同じパターン番号を複数のフレームで使えば、同じフレーズを繰り返せます。

## はじめての曲づくり

1. `File` → `New` で新しい曲にします。
2. `Space` で編集モードにします（カーソルとパターンの行が赤くなります）。
3. `Pattern` ウィンドウで、Pulse 1 の `00` 行にカーソルを置き、`Z` を押します。`C-4` が入り、カーソルが `Step` の行数だけ下がります。
4. 続けて `X` `C` `V` … と押すと、D E F … が入ります。`Q` の段は1オクターブ上です。
5. `Tab` で Triangle に移って、ベースを入れます。
6. `F5` で最初から再生します。もう一度 `Enter` を押すと止まります。
7. `Frames` ウィンドウの `Add` でフレームを増やし、続きを書きます。
8. `Ctrl+S` で保存します。

編集モードがオフのときにノートのキーを押すと、書き込まずに試聴だけします。

## キー操作

テキスト入力欄を編集していないとき、キーはどのウィンドウにフォーカスがあってもパターンへの入力になります。
ツールの中でも `Help` → `Keyboard Shortcuts` で一覧を見られます。

### ノート入力

キーボードをピアノの鍵盤に見立てます。キーは物理的な位置で判定するので、日本語キーボードでも同じ位置です。

```
 段          キー                                     音
 数字の段     2 3   5 6 7   9 0                       上の段の黒鍵
 Q の段      Q W E R T Y U I O P                     C D E F G A B C D E（1オクターブ上）
 A の段       S D   G H J   L ;                        下の段の黒鍵
 Z の段      Z X C V B N M , . /                     C D E F G A B C D E（現在のオクターブ）
```

| キー | 入力 |
| --- | --- |
| `1` | ノートオフ `---`（音を止める） |
| `-` | ノートリリース `===`（インストゥルメントをリリース点の先へ進める） |
| テンキー `/` `*` | オクターブを下げる / 上げる（ツールバーの `Octave` でも変更可） |

Noise チャンネルでは、16段階の高さ（`0-#`〜`F-#`、`F-#` が最も高い）が鍵盤に繰り返し割り当てられます。

### 編集

| キー | 操作 |
| --- | --- |
| `Space` | 編集モードの切り替え |
| `0`〜`9` `A`〜`F` | インストゥルメント・音量・エフェクト値の入力（16進。編集モード中） |
| `F` `B` `D` `C` | エフェクトの種類（エフェクト列の1文字目。編集モード中） |
| `Delete` | カーソル位置を消去（編集モード中）。ノート列ではノート・インストゥルメント・音量をまとめて消去。範囲を選択しているときは、選択範囲を消去 |
| `Ctrl+Z` | 元に戻す |
| `Ctrl+Y` / `Ctrl+Shift+Z` | やり直す |

元に戻せるのは、パターンの入力だけでなく、フレーム・インストゥルメント・曲の設定の変更も含めた直近100回分です。
テキスト入力欄への入力は、入力欄から抜けたときにまとめて1回分になります（入力中の `Ctrl+Z` は入力欄の中で効きます）。
曲を開き直したり新しく作ったりすると、履歴は消えます。

### 範囲選択とコピー・貼り付け

| キー | 操作 |
| --- | --- |
| `Shift+矢印キー` / `Shift+PageUp` など | カーソルを動かして範囲を選択（フレームはまたぎません） |
| マウスでドラッグ | 範囲を選択。`Shift+クリック` で選択範囲を広げる |
| `Ctrl+A` | カーソルのチャンネルを全選択。もう一度押すとフレーム全体を選択 |
| `Escape` | 選択を解除 |
| `Ctrl+C` | 選択範囲をコピー（選択していなければカーソル位置の欄） |
| `Ctrl+X` | 切り取り（コピーして消去） |
| `Ctrl+V` | カーソルの行・チャンネルから貼り付け |

- 選択は、ノート・インストゥルメント・音量・エフェクトの欄単位です。
- 貼り付けは、コピーした欄と同じ欄に入ります（音量をコピーしたら音量の欄へ）。複数チャンネルをコピーしたときは、カーソルのチャンネルから右へ順に貼り付けます。
- 1チャンネルのエフェクト列だけをコピーしたときは、カーソルのあるエフェクト列から貼り付けます。エフェクトを別の列へ移すのに使えます。
- パターンの末尾を超える行と、エフェクト列の数を超える欄は貼り付けません。
- Noise 以外のノートを Noise に貼り付けると、16段階の高さに折り返します。
- コピー・切り取り・貼り付けは編集モードでなくても使えます。間違えたら `Ctrl+Z` で戻せます。
- クリップボードはトラッカーの中だけのものです。別の曲を開いても残るので、曲の間でコピーできます。
- メニューの `Edit` からも操作できます。

## パターンの書き方

1チャンネル分のセルは次の形です。

```
C-4 00 F F06
│   │  │ └─ エフェクト（列の数は1〜4。チャンネル名を右クリックして変更）
│   │  └─── 音量（0〜F）
│   └────── インストゥルメント番号（16進）
└────────── ノート
```

- 空の欄は `.` で表示されます。インストゥルメントや音量を省略すると、直前の値が続きます。
- ノートは、次のノートかノートオフ `---` が来るまで鳴り続けます。
- 音量列は、インストゥルメントの音量に掛け合わせます（`F` でそのまま、`7` で約半分）。
- Triangle には音量がありません。音量が0より大きければ常に最大の音量で鳴ります。
- チャンネル名をクリックするとミュートできます（`[M]` が付きます）。

## インストゥルメント

`Instruments` ウィンドウで追加・複製・削除し、選んだインストゥルメントがノート入力に使われます。
削除すると、パターン中のインストゥルメント番号も詰め直します。

音量とデューティは、FamiTracker と同じMML形式で入力します。値は1tick（約1/60秒）ごとに1つ進みます。

```
15 14 12 10 | 8 6 / 4 2 0
```

| 記号 | 意味 |
| --- | --- |
| `\|` | この後ろの値がループ点。末尾まで来たらここに戻る |
| `/` | この後ろの値がリリース点。ノートが鳴っている間はここで止まり、`===` が来たら次へ進む |

- ループ点もリリース点もなければ、最後の値を保ちます。
- ループ点がリリース点より前にあれば、ノートが鳴っている間はその間を繰り返します（ビブラートのような揺れに使えます）。
- 音量は0〜15、デューティは0〜3（0=12.5%, 1=25%, 2=50%, 3=75%）です。Noise ではデューティの bit0 がモード（1=短周期の金属的な音）になります。
- 空のシーケンスは、音量なら常に15、デューティなら常に0です。
- `Preview (C-4)` ボタンを押している間、選んだインストゥルメントが Pulse 1 で鳴ります。

例:

| 用途 | 音量 | デューティ |
| --- | --- | --- |
| 減衰するリード | `15 14 13 12 11 10 10 9 9 / 8 5 3 1 0` | `2` |
| エコー（別チャンネルで2行遅らせて鳴らす） | `6 6 5 5 4 4 3 3 2` | `1` |
| ハイハット（Noise） | `10 6 3 1 0` | `0` |

## DPCM

DPCM チャンネルは、録音した音（サンプル）を鳴らします。ドラムやベースの音によく使います。

1. `View` → `DPCM Samples` を開き、`Import...` で WAV・FLAC・MP3・`.dmc` ファイルを読み込みます。
2. `Instruments` でインストゥルメントを選び、`DPCM Keys` でノート（`Key`）にサンプル（`Sample`）を割り当てます。
3. パターンの DPCM チャンネルに、そのインストゥルメントでノートを打ち込みます。

- ノートごとに、別のサンプルやレートを割り当てられます。1つのインストゥルメントで、キック・スネア・タムを鍵盤に並べるような使い方ができます（FamiTracker と同じです）。
- DPCM チャンネルでノートを打ち込む（または試聴する）と、`DPCM Keys` の `Key` がそのノートに切り替わります。
- `Rate` は再生の速さです（0〜15。15 が最も速く高い）。サンプルを作ったレートで鳴らすと元の高さになります。
- `Loop` をオンにすると、ノートリリース `===` が来るまでサンプルを繰り返します。
- `---` で止めます。止めた後も、すでに読み込んだ一瞬（最大16bit）は鳴ります。
- 音量列とインストゥルメントのシーケンスは、DPCM では使いません。

### サンプルの読み込み

WAV・FLAC・MP3 は、`Import Settings` の設定で DMC の形式に変換して読み込みます。設定は [ocf_dmcconv](../dmcconv/README.md) と同じです。

| 設定 | 既定 | 内容 |
| --- | --- | --- |
| `Rate` | `Auto` | レート。`Auto` は4081バイトに入る一番高いレート |
| `Normalize` | オフ | ピークを最大音量にそろえる |
| `Gain` | 0 dB | 音量 |
| `Trim` | オン（−50 dBFS） | 前後の静かな部分を削る。発音が遅れないように、既定でオンです |
| `Level` | 64 | 波形の中心。鳴らし始めと鳴り終わりのレベル |
| `Greedy` | オフ | オフは誤差が最小になる変換、オンは FamiTracker と同じ考え方の変換 |
| `Truncate` | オフ | 長すぎるサンプルを切り詰める |

- 読み込むと、ウィンドウの下に結果（`SNR` と `overload`）が出ます。`overload` が大きいときは、波形の変化に追いつけずに歪んでいます。`Gain` を下げて `Convert Again` を押すと、同じファイルを設定を変えて変換し直します（最後に読み込んだファイルを選んでいる間だけ）。
- 変換し直してレートが変わると、そのサンプルを元のレートで鳴らしていたキーも新しいレートになります。
- `.dmc` はそのまま読み込みます。レート（`Rate`）と鳴らし始めのレベル（`Rest Level`）は、サンプルの設定で合わせてください。
- サンプルは曲のファイルに入ります。全部で16KBまでで、ウィンドウの上の棒グラフに使用量が出ます。
- `Export...` でサンプルを `.dmc` ファイルに書き出せます。
- `Preview` を押している間、選んだサンプルをそのレートで鳴らします。

## エフェクト

| エフェクト | 内容 |
| --- | --- |
| `Fxx` | `01`〜`1F`: スピードを変える。`20`〜`FF`: テンポを変える |
| `Bxx` | この行の後、フレーム `xx` へ移る（ループに使う） |
| `Dxx` | この行の後、次のフレームの行 `xx` へ移る（パターンを途中で切り上げる） |
| `Cxx` | この行の後、曲を止める（曲の終わりに使う） |

何もしないときは、最後のフレームの後に先頭のフレームへ戻ります。
BGMで前奏だけを飛ばしてループしたいときは、最後のフレームの最終行に `B01` などを置きます。

## テンポと行の決め方

1行の長さは `Speed` と `Tempo` で決まります（FamiTracker と同じ計算です）。

```
1行の長さ（tick） = 150 × Speed ÷ Tempo        1tick ≒ 1/60秒
```

まず、**曲で使う一番短い音符を1行にします**。次に、目的のBPMになるように `Speed` と `Tempo` を選びます。

| 一番短い音符 | 1拍（4分音符） | 1小節（4/4） | BPM150 にする設定 | BPM120 にする設定 |
| --- | --- | --- | --- | --- |
| 16分音符 | 4行 | 16行 | Speed 6 / Tempo 150 | Speed 6 / Tempo 120 |
| 32分音符 | 8行 | 32行 | Speed 3 / Tempo 150 | Speed 3 / Tempo 120 |

- 1行のtick数が割り切れる設定にすると、テンポが揺れません。たとえば Speed 3 / Tempo 150 はちょうど3tick/行です。割り切れない設定でも鳴りますが、1行が3tickと4tickに交互に揺れたり、長い曲で少しずつずれたりします。
- `Rows`（1パターンの行数）は、小節の区切りに合わせると扱いやすくなります。1拍8行なら、64行で2小節です。
- 1行が短いほど、インストゥルメントのシーケンスが1音の間に進む数も少なくなります。32分音符を3tickで鳴らすと、1音の間に3ステップしか進みません。
- パターンのハイライトは4行・16行ごとです。1拍4行のときに拍・小節と一致します。

## 保存と読み込み

`File` メニューから操作します。

| メニュー | 内容 |
| --- | --- |
| `New` | 新しい曲 |
| `Open...` | JSONファイルを開く |
| `Open Demo Song` | 組み込みのデモ曲を開く |
| `Save` | 上書き保存（まだ保存していなければ `Save As...` と同じ） |
| `Save As...` | 名前を付けて保存。拡張子を省略すると `.json` を付けます |
| `Export WAV...` | WAVファイルに書き出す（[WAVに書き出す](#wavに書き出す)） |

- ファイルの選択はツール内のダイアログで行います。フォルダは一覧のクリック、`Up`、パスの直接入力で移動できます。
- 最初は `assets/songs` を開きます（無ければ保存時に作ります）。
- 既にあるファイルへ保存するときは、置き換えてよいか確認します。
- 変更があるときに `New` や `Open...` を選ぶと、破棄してよいか確認します。**ウィンドウを閉じるときは確認しない**ので、先に保存してください。
- 読み込みに失敗すると、問題の場所を示すメッセージが出ます（例: `/patterns/3/rows/7/note: invalid note "H-4"`）。

保存したJSONは人が読める形式なので、テキストエディタで直すこともできます。形式は [docs/tracker-format.md](docs/tracker-format.md) を参照してください。

## WAVに書き出す

`File` → `Export WAV...` で、曲を16bitモノラルのWAVファイルに書き出せます。
音はトラッカーやゲームで再生したときと同じです（同じAPUのエミュレーションで計算します）。

1. 設定のダイアログで、次の項目を選びます。下に、書き出される長さが表示されます。

   | 項目 | 内容 |
   | --- | --- |
   | `Sample rate` | 48000 Hz または 44100 Hz |
   | `Play count` | ループする曲を何回再生するか（1〜16） |
   | `Fade out` | 最後の再生の後のフェードアウトの長さ（0〜10秒）。0のときは、最後の再生が終わった位置でぴったり切ります |

2. `Export...` を押して、保存先を選びます（最初の名前は曲のファイル名に `.wav` を付けたもの）。
3. 書き出しはバックグラウンドで行われ、進捗バーが出ます。`Cancel` で中止できます。

曲の終わり方によって、書き出す長さが決まります。

- `Cxx` で止まる曲は、止まったところで終わります（`Play count` と `Fade out` は使いません）。
- `Cxx` が無い曲はループするので、`Play count` 回再生してからフェードアウトします。最後のフレームから先頭に戻ったときや、`Bxx` で前に戻ったときを「次の再生の始まり」として数えます。前奏の後に `B01` で戻る曲なら、前奏は最初の1回だけ入ります。
- ゲームのループ素材にしたいときは、`Play count` を 1、`Fade out` を 0 にします。

補足:

- ミュートしているチャンネルも含めて、すべてのチャンネルを書き出します。
- 書き出し中も曲の編集を続けられます（書き出しを始めた時点の曲が書き出されます）。
- 書き出しにかかる時間は、3分半の曲で Release ビルドが約3秒、Debug ビルドが約6秒です。
- いったん `<ファイル名>.tmp` に書いてから置き換えるので、中止や失敗で既存のファイルが壊れることはありません。

## ゲームで再生する

```cpp
#include <ocf/audio/AudioSystem.h>
#include <ocf/audio/tracker/SongSerializer.h>
#include <ocf/platform/FileSystem.h>

auto result = audio::tracker::SongSerializer::load(
    FileSystem::getInstance()->getAssetFullPath("songs/canon_in_d.json"));
if (result.isErr()) {
    OCF_LOG_ERROR("{}", result.unwrapErr());
    return;
}

auto& audioSystem = engine.getAudioSystem();
audio::AudioSourceHandle bgm = audioSystem.createTrackerSource();
audioSystem.play(bgm); // ソースをミキサーに載せる（曲はまだ鳴らない）

audioSystem.tracker_setSong(bgm,
                            std::make_shared<const audio::tracker::Song>(std::move(result).unwrap()));
audioSystem.tracker_play(bgm); // 曲の先頭から再生

// 止めるとき
audioSystem.tracker_stop(bgm);

// 終了時
audioSystem.stop(bgm);
audioSystem.destroySource(bgm);
```

- 曲は専用のAPUでオーディオスレッドから鳴ります。`tracker_play()` などはメインスレッドから呼べます。
- `tracker_getStatus()` で再生中かどうかと、再生位置（フレーム・行）を取れます。
- 渡した `Song` はオーディオスレッドと共有されるので、渡した後に変更してはいけません。

エンジン側の仕組みは [docs/tracker.md](../../docs/tracker.md) にまとめています。

## 制限事項

- DPCM の `Zxx`（レベルの設定）・`Yxx`（途中から再生）などのエフェクトはまだありません。
- インストゥルメントのアルペジオ・ピッチのシーケンスと、ピッチ系のエフェクト（`0xy` `1xx` `2xx` `3xx` `4xy` など）はまだありません。
- 元に戻した後も、ファイル名の `*`（未保存の変更あり）は消えません。
- ウィンドウのサイズ変更には対応していません（エンジン側の制限）。
- ウィンドウの配置は、起動したフォルダの `imgui.ini` に保存されます。
